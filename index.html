Как мы делаем видео с Claude

Схема на старте. Меняем её, когда найдём способ лучше.

  1. Три проекта Claude, по одному на канал

    History, What If и Generations. В инструкции проекта: ниша и рубрики, стиль, голос озвучки, формат ответа. В файлы проекта кладём сценарии-примеры, которые получились лучше всего.

  2. Новый чат на каждое видео

    Внутри проекта канала пишем тему и получаем всё в одном чате: сценарий, список кадров с промптами для картинок, текст для озвучки, название, описание и хэштеги. Описание зависит от сценария, поэтому отдельный чат для описаний не нужен.

  3. Голос, картинки и монтаж в своих сервисах

    Видео целиком Claude не делает. Озвучка в ElevenLabs, картинки в Nano Banana, сборка в CapCut или Premiere (подборка Said в задаче про инструменты). У каждого канала свой голос.

  4. Своя платформа для загрузки на три канала

    Одна страница: выбрал канал → видео, превью, название, описание, хэштеги, время публикации → загрузка через YouTube Data API. Можно ставить публикацию по расписанию. Лимит API: 100 загрузок в день. Делаем после того, как созданы каналы.

  5. Публикация прямо из чата Claude

    Подключаем платформу к Claude как свой коннектор (MCP): кидаешь в чат превью и описание, Claude публикует и перед каждой публикацией спрашивает подтверждение. Тяжёлые видеофайлы удобнее грузить сразу в платформу.

  6. Пометка ИИ-контента

    Реалистичные сгенерированные видео YouTube просит помечать. В API для этого есть поле containsSyntheticMedia, его включаем в платформе.

Порядок задач

Said создаёт каналы → Emir загружает оформление, Almaz делает платформу загрузки → публикация из чата. Сценарии Almanbet и проекты Claude можно делать параллельно. На доске такие связи видны по пометке «После: …» на карточке.

Задачи на старте разложены по ролям, их можно менять. Срок ставится в задаче: датой или кнопками «Завтра», «Через неделю». «Горят сроки» показывает просроченное и то, что надо сдать в ближайшие два дня. Задачи перетаскиваются между колонками мышкой, на телефоне статус меняется внутри задачи.
