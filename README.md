# Доска студии

Доска задач команды (Almaz, Almanbet, Said, Emir) для YouTube-каналов History, What If и Generations.

- Сайт: https://almaz192.github.io/studio-board/
- Задачи хранятся в файле `data.json` в ветке `data`. Каждое изменение на доске сохраняется туда отдельным коммитом.
- Чтобы менять задачи, на сайте нажмите «Подключить» и вставьте ключ доступа GitHub (fine-grained token с правом Contents: Read and write только на этот репозиторий). Без ключа доска открывается для просмотра.
