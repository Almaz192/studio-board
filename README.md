# Доска студии

Доска задач команды (Almaz, Almanbet, Said, Emir) для YouTube-каналов History, What If и Generations.

- Сайт: https://almaz192.github.io/studio-board/
- Задачи хранятся в бесплатной базе Google Firebase (проект `studio-board-ee2d2`, Firestore). Никаких ключей вводить не нужно: всё работает по ссылке.
- Ветка `data` хранит старую копию задач, из неё база заполнилась при первом запуске.
